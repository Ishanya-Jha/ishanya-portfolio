# Ishanya Jha — Portfolio

A responsive React + Vite portfolio based on the approved dark plum / orchid / coral design.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`.
